Local Issue Tracker

Release notes

A fully local personal issue tracker: floating workspaces, configurable fields, waiting metrics, and a dark-mode-first UI. History below is from the GitHub main branch, 9 Aug 2026 through 10 Sep 2026.

— commits — features 9 Aug – 10 Sep 2026 Repo primalBeast/local-issue-tracker

Latest

10 Sep 2026 — Windows install on work PCs

  • install.cmd now runs uv sync --native-tls so HTTPS interception on a work laptop no longer fails the install.
  • The Windows 11 run guide uses the same flag for manual uv sync and reinstall.
  • This HTML release-notes page is in the repo root and is updated on each commit and push.

10 Sep 2026 — Random theme & All Items flash

  • Theme menu gained a Random button that previews another wallpaper.
  • Closing the theme dialog (button or click outside) keeps the highlighted theme.
  • All Items in-place editors overlay the cell so the row does not jump.
  • Saving a changed list cell flashes the new value so it is easy to spot.

Video themes

Looping full-bleed videos: Sakura, Oasis, Reef, Umbra, Ueno, and Fog Bridge. Still UFO wallpapers (Roswell, mothership, crop circles, and more) sit in their own theme group.

All Items as a working table

Search, primary and secondary sort, Assigned name lists, notes hover, a waiting calendar, and right-click in-place edit (ticket number stays read-only). Double-click opens a ticket; an open-dot marks the focused item.

What this app became

Board & canvas

  • Free-floating panels: drag, resize from any edge or corner, snap.
  • Unlimited pan; Ctrl+drag pans even over panels; pointer-centered zoom.
  • Compact tiles when zoomed out; Focus zoom; filter row on the board.
  • Drag panels from field labels; in-app board remove and tab reorder.

Tickets, waiting, notes

  • Title bar, integer urgency, waiting checkbox + since date + name select.
  • Per-project URL prefix and External Fixing ticket links.
  • Notes: larger text, Ctrl+Q strikethrough, Ctrl+; date stamp under the caret.
  • Hourly readable txt/md snapshots; daily folder backups.

Templates

  • Project template editor and Save as Template.
  • Line/slot placement, live preview, width percentages, collapsible groups.
  • Hidden-until conditions noted on line headers.

Windows & local-first

  • Binds to 127.0.0.1; data under OneDrive (AppData fallback).
  • install.cmd / start.cmd; uv sync --native-tls for work PCs; committed UI bundle.
  • macOS and Windows 11 run guides.

Theme library

Grouped in the picker: Night skies, Solar system, Night cities, Earth, Japan, Alien worlds, Sakura, Samurai, Switzerland, Ocean, Underwater, Alien ocean, Alien depths, UFOs, and Video.

Changelog

Updated whenever this repo is committed and pushed to GitHub. Bundle-rebuild chores are hidden by default — they ship the production UI so Windows clones can run without Node.
