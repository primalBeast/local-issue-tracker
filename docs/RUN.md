# How to run Local Issue Tracker

Pick the guide for your computer:

| OS | Guide |
|----|--------|
| **macOS** | [RUN-macOS.md](./RUN-macOS.md) |
| **Windows 11** | [RUN-Windows11.md](./RUN-Windows11.md) |

Both guides include:

1. What to download and install  
2. How to clone this repository  
3. How to install dependencies with **uv**  
4. How to start the local web server  
5. Where your data is stored  
6. Troubleshooting  

### Quick links (downloads)

| Tool | macOS | Windows 11 |
|------|-------|------------|

| Browser | Safari / Chrome / Firefox / Edge | Edge (built-in) / Chrome / Firefox |
| Node.js (optional) | [nodejs.org](https://nodejs.org) LTS | [nodejs.org](https://nodejs.org) LTS |
